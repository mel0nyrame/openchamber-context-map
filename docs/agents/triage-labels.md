# Triage labels

The skill uses five canonical triage roles. This file maps those roles to the label strings actually used by this repository's issue tracker.

| Label in mattpocock/skills | Label in this repository | Meaning |
| -------------------------- | ------------------------ | ------- |
| `needs-triage`             | `needs-triage`           | A maintainer needs to assess it |
| `needs-info`               | `needs-info`             | Waiting for the reporter to add information |
| `ready-for-agent`          | `ready-for-agent`        | Fully described and ready for an AFK agent |
| `ready-for-human`          | `ready-for-human`        | Requires human implementation |
| `wontfix`                  | `wontfix`                | Will not be addressed |

When the skill mentions a role (for example, "apply the AFK-ready triage label"), use the corresponding label string from the table.
