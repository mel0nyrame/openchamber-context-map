# AGENTS.md

## Engineering conventions

- After changing `src/`, run `bun run build` and commit the three build artifacts together; extension installation does not run a build. See `docs/adr/0004-build-artifacts-committed.md` for the rationale.
- `bun test` and `bun run typecheck` must pass before delivery.
- Put panel geometry, rounding, colors, and refresh policy in pure-function modules (`src/panel/map.ts`, `palette.ts`, `refresh.ts`) and unit-test them; switch themes with the `data-oc-theme` selector, never by reading the system preference.
- Layer failure states by source: host failure, Collector unavailable, and a single failed request each get their own state and copy; do not merge them into one generic error. See `docs/adr/0008-degradation-layers.md` for the rationale.
- The installer accepts only an empty target or a target generated by this tool, and stops on conflict while preserving the original file; when rewriting `extensions.json`, preserve unknown fields. See `docs/adr/0010-installation.md` for the rationale.
- Panel copy lives only in `src/panel/i18n.ts`, and rendering code reads it through `t(locale, key)`; `en` is the source language, `zh` is a translation, and other locales fall back to `en`. See `docs/adr/0013-panel-localization.md` for the rationale.
- Persistence stores only `SnapshotSummary` (including item heads), not previews; changing its fields requires bumping `SNAPSHOT_SCHEMA_VERSION`, and old files are discarded on a version mismatch. See `docs/adr/0014-snapshot-persistence.md` for the rationale.
- README and ADRs are primarily English; Chinese versions use the `.zh.md` suffix (`README.zh.md`, `docs/adr/0001-….zh.md`), and both must change together. `docs/agents/` is English; other internal docs under `docs/` are in Chinese.
- See `docs/opencode-plugin.md` for the OpenCode V2 plugin interface and verified facts.

## Agent skills

### Issue tracker

Issues and specs live in this repository's GitHub Issues (`mel0nyrame/openchamber-context-map`) and are managed through the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The default five-role vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single context: `GLOSSARY.md` at the repository root, with ADRs in `docs/adr/`. See `docs/agents/domain.md`.
